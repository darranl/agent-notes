# Agent Notes

This repository serves as a collection of documentation, guides, and context to assist developers working on WildFly, with a particular emphasis on WildFly Elytron development.

## Purpose

The `agent-notes` repository is designed to help WildFly developers with:
- **Development workflows** - Step-by-step guides for common development tasks (version bumps, schema changes, etc.)
- **PR review guidelines** - Checklists and criteria for reviewing pull requests
- **Issue triage and reproduction** - Setup guides and procedures for reproducing end-user issues
- **Best practices** - Documented patterns and conventions for WildFly development
- **AI-assisted development** - Context and instructions for AI agents to provide consistent, informed assistance

## Scope

This repository focuses on the day-to-day work of engineers developing WildFly Elytron and related WildFly subsystems. Content includes:
- Feature development processes
- Testing requirements and patterns
- Version management (model and schema)
- Code review standards
- Debugging and troubleshooting guides
- Environment setup for reproducers

## Structure

Content is organized by topic in subdirectories:
- **`feature-development/`** - Guides for implementing and reviewing features
- Additional directories will be added as content grows
