# Agent Notes

This repository serves as a collection point for notes, documentation, and context related to AI agent interactions and workflows.

## Purpose

The `agent-notes` repository is designed to:
- Store notes about agent interactions and development workflows
- Document AI assistant usage patterns and best practices
- Maintain context and instructions for future agent sessions
- Provide project-specific guidance for AI-assisted development

## Structure

As content is added to this repository, it will be organized to facilitate easy access and reference by both humans and AI agents.

## Usage

This repository is intended to be referenced by AI assistants (like Bob Shell) to maintain context across sessions and provide consistent, informed assistance on projects and workflows.

## AGENTS.md

The `AGENTS.md` file in this repository provides specific guidance to AI agents when working with content here. It should be kept up-to-date as the repository evolves.
